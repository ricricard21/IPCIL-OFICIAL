# IPCI Web

Sitio institucional de una sola página preparado para GitHub Pages.

## Contenido
- `index.html` → estructura principal del sitio
- `styles.css` → estilos visuales
- `script.js` → interacciones básicas
- `assets/` → logo, sello y logos de empresas aliadas
- `CNAME` → archivo vacío para dominio personalizado si lo deseas

## Publicación en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta al repositorio.
3. En GitHub entra a **Settings > Pages**.
4. En **Source**, selecciona la rama principal (`main`) y la carpeta raíz (`/root`).
5. Guarda los cambios y GitHub publicará tu sitio.

## Dominio personalizado
Si usarás un dominio propio, edita el archivo `CNAME` y escribe allí tu dominio, por ejemplo:
`www.tudominio.com`

Si no usarás dominio propio por ahora, puedes dejar el archivo vacío o eliminarlo.

## Validación de certificados
El formulario de validación está listo a nivel visual.
Más adelante se puede conectar con:
- Google Sheets
- Apps Script
- una base de datos
- un backend propio
